BUILD A COMPLETE FULL-STACK MOVIE & TV DISCOVERY PLATFORM

Create a production-ready movie and TV discovery/streaming frontend and backend.

The application should reproduce the supplied reference UI as closely as possible in:
- layout
- spacing
- typography hierarchy
- navigation
- colors
- card proportions
- page composition
- filtering
- content density
- responsive behavior
- animations
- interactions
- detail-page structure
- personal-library UX

Do not use the reference site's branding, logo, name, proprietary assets, text, or identity.

Create an original brand identity while preserving the same overall UI/UX structure and visual language.

Use TMDB as the primary metadata/content API.

==================================================
TECH STACK
==================================================

Frontend:

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui where useful
- Lucide icons
- next/image where appropriate
- Server Components where beneficial
- Client Components only where interaction/state is required

Backend:

- Next.js server-side API routes / route handlers
- TypeScript
- TMDB API integration
- PostgreSQL
- Prisma ORM
- Secure authentication/session system
- Server-side caching
- Request validation
- Rate-limit protection
- Environment-based secrets

Do not expose the TMDB access token to the browser.

Use server-side TMDB requests.

TMDB API base:

https://api.themoviedb.org/3

Use the TMDB API Read Access Token through:

Authorization: Bearer ${TMDB_ACCESS_TOKEN}

Store credentials in environment variables.

Example:

TMDB_ACCESS_TOKEN=
DATABASE_URL=
NEXTAUTH_SECRET=

Never hard-code secrets.
